# Deine ATEM-PAUSE

Somatische Übungen für Ruhe & Kraft – eine App für Mamas, Fotografinnen und alle Frauen, die ihr Nervensystem regulieren möchten.

## Was ist das?

Eine interaktive Web-App mit kostenlosen und Premium-Übungen für somatische Nervensystemregulation. Schnell, einfach, offline nutzbar.

## Features

✅ **4 kostenlose Übungen** - sofort sichtbar  
✅ **50+ Premium-Übungen** - mit Unlock-Code freischaltbar  
✅ **SVG-Illustrationen** - für jede Übung  
✅ **Deutsche Texte** - warmherzig, nicht klinisch  
✅ **Mobil-optimiert** - responsive Design  

## Kostenlose Übungen

1. **Erdung: Mit beiden Füssen ankommen** (3 min)
2. **Box Breathing: Der 4-4-4-4 Rhythmus** (3 min)
3. **Die 5 Sinne: Jetzt-Verankerung** (5 min)
4. **Erdungs-Atemzug: Die Universalübung** (2 min)

## Premium Übungen (Beispiele)

- Schulter-Puls: Spannung lösen
- Gegenpol-Berührung: Erwachen
- Anspannen & Loslassen
- 4-7-8 Atem: Der Einschlaf-Trick
- Vagal Summen
- Mama-Moment: Geduld zurückgewinnen
- Fotografin-Mut
- ...und viele mehr

## How to Deploy

Dieses Projekt ist auf **Netlify** deployed und mit **GitHub** verbunden.

Jeder Push zu `main` → automatisches Update der Live-App.

### Struktur

```
atem-pause/
├── nervensystem-app-mit-illustrationen.html  (die App)
├── README.md  (diese Datei)
├── netlify.toml  (Netlify-Konfiguration)
└── .gitignore
```

## Änderungen machen

1. Öffne die HTML-Datei in deinem Editor
2. Ändere etwas (z.B. Text, Übungen, Farben)
3. Speichern → `git add .` → `git commit -m "...message..."` → `git push`
4. Warte 1-2 Minuten → Netlify deployed automatisch
5. Live-URL aktualisiert sich selbst
