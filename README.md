# ATEM-PAUSE – Dein Nervensystem

**Somatische Übungen für Ruhe & Kraft** – eine PWA (Progressive Web App) für Mamas, Fotografinnen und alle Frauen, die ihr Nervensystem in Balance halten möchten.

---

## 🎯 Was ist ATEM-PAUSE?

Eine **interaktive Offline-App** mit somatischen Übungen:
- ✨ **12 kostenlose INTRO-Übungen** zum Kennenlernen
- 🚀 **100+ Premium-Übungen** für tiefere Regulation
- 📱 **Installierbar auf dem Homescreen** wie eine echte App
- 🔒 **Offline verfügbar** – funktioniert ohne Internetverbindung
- 💾 **Code wird lokal gespeichert** – nur einmalig eingeben

**Für Stress, Reizbarkeit, Angst & Erschöpfung:**
- Erdung & Verankerung
- Atemtechniken (Box Breathing, 4-7-8 Atem)
- Körperübungen (Schulter-Puls, Anspannen & Loslassen)
- Vagale Techniken
- Spezial-Übungen für Mamas und Fotografinnen

---

## 🚀 Installation

### Auf der Website (atem-pause.vercel.app)

1. **Im Browser öffnen** (Desktop oder Handy)
2. **"Zur App machen" oder "Install" antippen** (Popup oben)
3. **Unlock-Code eingeben** – erhalten per E-Mail nach Kauf
4. **Fertig!** App funktioniert offline, Code bleibt gespeichert

### Offline-Datei herunterladen

Alternativ kannst du die `index.html` lokal speichern und jederzeit offline öffnen – funktioniert auf Windows, Mac, iOS und Android.

## 📱 Features

- **Responsive Design** – funktioniert auf Handy, Tablet, Desktop
- **Dark Mode friendly** – angenehme Farben
- **Offline-Betrieb** – Service Worker cached alles
- **Gespeicherte Session** – localStorage speichert den Code
- **Code wechseln** – "Code wechseln"-Button am Ende
- **Modal-Navigation** – vor/zurück durch Übungen
- **PWA Install** – Homescreen-Installation auf iOS und Android

---

## 🛠 Technologie

- **HTML5** + **CSS3** + Vanilla **JavaScript**
- **Progressive Web App (PWA)** mit Service Worker
- **manifest.json** für Installation
- **localStorage** für Datenspeicherung
- **100% Offline-first**
